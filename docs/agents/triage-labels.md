# Triage Labels

这些 skills 用五个规范的 triage 角色来描述状态。本文件把这些角色映射到本仓库 issue tracker 中实际使用的 label 字符串。

| mattpocock/skills 中的 label | 本仓库 tracker 中的 label | 含义                                 |
| ---------------------------- | ------------------------- | ------------------------------------ |
| `needs-triage`               | `needs-triage`            | 需要维护者评估该 issue               |
| `needs-info`                 | `needs-info`              | 等待报告者提供更多信息               |
| `ready-for-agent`            | `ready-for-agent`         | 已完整描述，可交给 AFK agent 处理    |
| `ready-for-human`            | `ready-for-human`         | 需要人工实现                         |
| `wontfix`                    | `wontfix`                 | 不会处理                             |

当某个 skill 提到某个角色（例如「apply the AFK-ready triage label」）时，使用上表对应行中的 label 字符串。

如需匹配实际使用的词汇，编辑「本仓库 tracker 中的 label」一列即可。
